# Person 3 Accessibility Checklist

- [x] Skip-to-content link added.
- [x] Visible keyboard focus styling exists.
- [x] Theme toggle has descriptive accessible names.
- [x] Accessibility settings dialog has a labelled heading and close control.
- [x] Reduced-motion preference supported, including OS preference.
- [x] Larger-text and higher-contrast preferences added.
- [x] Toast messages use a polite live region.
- [x] Voice features retain text-input/browser fallbacks.
- [ ] Full keyboard walkthrough in a browser.
- [ ] Screen-reader walkthrough.
- [ ] Automated WCAG/axe audit.
- [ ] Contrast measurement for every UI state.
- [ ] Test speech features in supported and unsupported browsers.

This checklist does not claim formal WCAG conformance; unchecked items require manual or automated validation.
