# PatchProof React UI — Person 3

A React + Vite UI inspired by the high-level visual language of 2une.ai: dark minimal hero, large typography, electric-blue accents, animated particle wave, clean capability sections, and a responsive workspace. This is a new PatchProof design, not a copied 2une website.

## Requirements
- Node.js 20+ recommended
- npm

## Run on Windows
1. Extract the project ZIP.
2. Open Command Prompt in `PatchProof_Person1_COMPLETE_ENGINE_QA`.
3. Run:
   ```cmd
   cd frontend-react
   npm install
   npm run dev
   ```
4. Open the local URL Vite prints (usually `http://127.0.0.1:5173`).

## Build production files
```cmd
cd frontend-react
npm install
npm run build
```

## Connect Person 1 artifacts
In the workspace, choose **Load reports** and select any combination of:
- `patchproof-report.json`
- `patchproof-usage-report.json`
- `verification.json`
- `ai-analysis.json` (when Person 2 produces it)
- `dependency-exit-capsule.json`

The app identifies files by filename and/or report fields. JSON is parsed in the browser; files are not uploaded to a remote service. Multiple files can be selected at once. If no data is loaded, the workspace starts empty. The fixture preview is explicitly labelled and is never represented as a real scan.

## Features
- Landing page with animated particle wave, responsive layout and reduced-motion support
- Dark/light mode
- Workspace navigation: overview, findings, dependency usage, AI migration, verification and Exit Capsule
- JSON artifact import and evidence explorer
- Voice read-aloud through browser Speech Synthesis
- Voice search through browser Speech Recognition when supported and permission is granted
- JSON and Markdown Exit Capsule export
- Clear pending states for missing AI and verification artifacts

## Important integration notes
- Person 2's Gemma 4 model is not included; the AI panel accepts the real JSON artifact when available and shows a pending state otherwise.
- The React UI does not claim to run a scan by itself. It visualizes reports generated by Person 1's engine. Use Person 1's documented command to generate reports, then import them in the UI.
- Browser speech recognition support varies. All actions remain available through standard controls.
- This frontend was source-checked in this build environment, but a browser-run and npm production build were not available to verify here. Run `npm install` and `npm run build` on your machine and report any errors.
